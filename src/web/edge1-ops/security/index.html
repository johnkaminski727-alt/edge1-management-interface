How this becomes a real control area

  1. Build the human interface. Plain-language status, action descriptions, confirmations, results, and evidence.
  2. Add secure browser sign-in. The browser receives a normal session, never an API signing secret.
  3. Connect a server-side action gateway. The gateway translates approved button requests into the existing allowlisted operations.
  4. Enable read-only checks first. Configuration validation is the first live action.
  5. Unlock changes one at a time. Rule reload, log rotation, and later sensor restart each get independent testing and authorization.

Design state: repository prototype only. No authentication, route, firewall, DNS, sensor, or traffic-control changes are made by this page.
